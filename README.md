# Blythe A4 Maker

โปรแกรม Windows สำหรับเลือกลาย Eye Chip แล้วจัดลงกระดาษ A4 ที่ 300 DPI โดยล็อกขนาดชิ้นงาน 14.5 mm พร้อมพรีวิว A4, เส้นตัด, ลบรายการล่าสุด และ cache รูปที่เตรียมแล้วเพื่อเปิดครั้งถัดไปได้เร็วขึ้น

## ติดตั้งแบบง่าย

1. ดาวน์โหลดไฟล์ `install.bat`
2. ดับเบิลคลิกไฟล์
3. โปรแกรมจะดาวน์โหลดเวอร์ชันล่าสุดไปที่ `Desktop\Blythe`, ติดตั้ง Pillow และเปิดโปรแกรมให้

ถ้าเครื่องยังไม่มี Python ตัวติดตั้งจะพยายามติดตั้ง Python ผ่าน `winget` ให้อัตโนมัติ

## เปิดโปรแกรมหลังติดตั้ง

ดับเบิลคลิก `run.bat` หรือ `เปิดโปรแกรมทำตาบลาย.bat`

ครั้งแรก ถ้าไม่พบโฟลเดอร์ลายตาเดิม โปรแกรมจะถามให้เลือกโฟลเดอร์ลายตา จากนั้นใช้ไฟล์หมายเลขในโฟลเดอร์นั้น เช่น `1.png`, `50.png`, `52.1.psd`

สามารถกดไอคอน `⚙` มุมบนของโปรแกรมเพื่อเปลี่ยนโฟลเดอร์ **Source Data** ได้ตลอดเวลา โปรแกรมจะจำโฟลเดอร์ล่าสุดไว้ใน `%APPDATA%\BlytheA4Maker\settings.json` และใช้ให้อัตโนมัติเมื่อเปิดครั้งถัดไป

ชื่อไฟล์ที่มีจุด เช่น `52.1` จะนับเป็น 1 ชิ้น ส่วนเลขปกติจะนับเป็น 1 คู่
