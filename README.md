# Blythe Eye Maker

โปรแกรม Windows สำหรับจัดไฟล์ Eye Chip ทั้งหน้า A4 และหน้า 4×6 นิ้ว พร้อมพรีวิว เลือกลายด้วยหมายเลข ลบรายการล่าสุด และสร้างไฟล์พร้อมพิมพ์ได้จากโปรแกรมเดียว

## ใช้งานแบบพร้อมเปิด

1. เปิดหน้า **Releases** ของ GitHub
2. ดาวน์โหลด `BlytheEyeMaker.exe`
3. ดับเบิลคลิกไฟล์เพื่อเปิดโปรแกรมได้ทันที

ไฟล์ Release เป็นโปรแกรม Windows แบบ standalone ไม่ต้อง clone โปรเจกต์และไม่ต้องติดตั้ง Python

## Source ที่ต้องตั้งค่า

ครั้งแรกโปรแกรมจะเปิดหน้าตั้งค่า Source ให้อัตโนมัติ:

- **Source A4 • ขายแบบ1** — เลือกโฟลเดอร์ `ขายเเบบ1` โปรแกรมจะอ่าน `ขายเเบบ2` ที่อยู่ข้างกันให้อัตโนมัติ
- **Source 4×6 • ไฟล์ตา** — เลือกโฟลเดอร์ `ไฟล์ตา` ที่เก็บไฟล์ 1800×1200 สำหรับหน้าคัสตอม 4×6

กดไอคอน `⚙` มุมบนเพื่อเปลี่ยน Source ภายหลังได้ โปรแกรมจะจำค่าล่าสุดไว้ใน `%APPDATA%\BlytheA4Maker\settings.json`

ถ้าใช้โครงสร้างเดิม ตัวอย่างคือ:

```text
...\ตาน้องบลาย\ขายเเบบ1
...\ตาน้องบลาย\ขายเเบบ2
...\ตาน้องบลาย\ไฟล์ตา
```

## ติดตั้งจาก source (สำรอง)

`install.bat` และ `run.bat` ยังเก็บไว้สำหรับกรณีที่ต้องการรันจาก source code

ชื่อไฟล์ที่มีจุด เช่น `52.1` จะนับเป็น 1 ชิ้น ส่วนเลขปกติจะนับเป็น 1 คู่
