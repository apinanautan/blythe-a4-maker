# Blythe Eye Maker

ใช้งานปกติ: ดับเบิลคลิก **เปิดโปรแกรม.bat** เท่านั้น

ไฟล์ระบบถูกเก็บไว้ในโฟลเดอร์ `app` และซ่อนไว้เพื่อไม่ให้หน้าโปรเจกต์รก ไม่ต้องเปิดหรือแก้ไขข้างใน

ถ้าเครื่องยังไม่มี Python ไฟล์เปิดโปรแกรมจะเรียกตัวติดตั้งให้อัตโนมัติ

หน้า AI มีปุ่ม **เปิดลิงก์ให้ลูกค้าออกแบบผ่านมือถือ** สำหรับเปิดหน้าออกแบบชั่วคราวให้ลูกค้าเลือกสไตล์ ลาย และสีได้จากโทรศัพท์ ลิงก์จะหมดเมื่อกด **ปิดลิงก์** หรือปิดโปรแกรม และจะสร้างพรีวิวไว้ในหน่วยความจำชั่วคราวเท่านั้น ไม่มีปุ่มดาวน์โหลดหรือการเปิดโฟลเดอร์ Source ให้ลูกค้า

หน้าเว็บมือถือเป็นรีโมทของโปรแกรมเท่านั้น: มือถือส่งตัวเลือกเข้ามา โปรแกรม Blythe บนเครื่องนี้จึงเป็นผู้เรียก GPT และสร้างรูป จากนั้นเว็บจะแสดงหน้าปกตัวอย่างที่โปรแกรมทำเสร็จแล้ว เมื่อลูกค้ากดบันทึก โปรแกรมจะเก็บรูปตา หน้าปก และตัวเลือกไว้ในโฟลเดอร์ `ลูกค้าเลือกจากลิงก์`

การแสดงรูปบนมือถือจำเป็นต้องส่งพิกเซลให้เบราว์เซอร์ จึงไม่สามารถป้องกันการแคปหน้าจอหรือการบันทึกด้วยเครื่องมือของเบราว์เซอร์ได้ทั้งหมด ระบบนี้ลดการเก็บไฟล์ด้วยการใช้พรีวิวขนาดเล็ก ปิดแคช และไม่ส่งไฟล์ต้นฉบับ
